# AiryView（エアリービュー）

Windows 11（64ビット）向けの、軽量ドキュメントビューアです。PDFを読み、原寸を意識して印刷できます。Markdown（.md）とテキスト（.txt）は閲覧・編集・保存ができ、画像（JPEG・PNG・TIFF・BMP・GIF・ICO・WebP・SVG）も開けます。

## ダウンロードとセットアップ

1. [最新版のダウンロード画面](https://github.com/MitsunobuSuhara/AiryView/releases/latest) を開きます。
2. **Assets** の `AiryView-*.zip` をクリックして保存します。
3. ZIPを右クリックして **すべて展開** を選び、展開したフォルダを開きます。
4. **AiryViewをセットアップ.cmd** をダブルクリックします。Windowsの確認が出たら、内容を確認して **はい** を選びます。

完了後は、スタートメニューの **AiryView** から開けます。更新するときも、AiryViewを閉じてから同じ手順です。

## できること

- Adobe Acrobat Readerのように、原本の用紙サイズや縮尺を保ち、原本に忠実にPDFを印刷出力
- PDF・Markdown（MD）・テキストファイル（TXT）・画像（PNG・JPEGなど）を、同じ画面のタブでまとめて管理
- テキストファイル（TXT）の新規作成・編集・保存
- Markdown（MD）の整形表示とソース編集を切り替えて、編集・保存

TXTは開いた画面でそのまま編集できます。MDは上部の `</>` ボタン（`Ctrl＋Shift＋M`）で編集表示へ切り替えます。どちらも `Ctrl＋S` で保存できます。

メモ画面の0の中の点はフォントの見た目です。文字そのものは普通の数字の0です。

## 画像編集・PDFへの書き込み（2.1.0）

画像・PDFを開き、左上の **鉛筆アイコン** から編集します。追加できるものは **文字・矢印・線・四角形・円／楕円・ハイライト** です。選択項目の右側には小さなアイコンが付きます。

- 文字は用紙をクリックして入力。入力欄左上の四方向アイコンをドラッグして位置を変え、右下のつまみで大きさを調整できます。隣の「書式」からフォント・サイズ・色を変更できます（初期色は黒）。
- 図形はドラッグして追加し、保存前なら移動・修正・削除できます。
- ハイライトは **範囲指定**（PDFの文字には自動で合わせる）と **フリーハンド** から選びます。画像やスキャンPDFでは範囲指定は四角い範囲になります。
- 画像は回転・サイズ変更に対応。**クリップ** は追加ツールとは別にあり、確定前に範囲を移動・調整できます。大きさはpxとcmの目安を表示します。

編集画面では `Ctrl＋マウスホイール` で拡大・縮小、`Ctrl＋Z／Ctrl＋Y` で元に戻す・やり直すができます。原本を守るため、保存は **別名で保存**（`Ctrl＋S`）です。画像はPNG／JPEGで保存できます。PDFの元の文章を直接書き換える機能ではありません。

無料で、追加の編集ソフトやDesktop Runtimeは不要です。編集機能は編集ボタンを押したときだけ読み込みます。詳しくは [編集機能の検証記録](docs/VISUAL-EDITOR-WIP.md) を参照してください。

## ページごとに用紙サイズ・向きが違うPDFの印刷

印刷プレビューでは、既定で **「ページごとに原本の用紙・向きに合わせる」** がオンです。A4・A3や縦・横が混在するPDFも、各ページに合う用紙と向きをプリンターへ指定します。「原寸・指定倍率」の100%では自動縮小しません。

全ページをA4などに統一する場合は、このチェックをオフにして用紙・向きを選びます。2ページ／枚・4ページ／枚・小冊子・ポスターも、指定した用紙を使います。

原本に対応する用紙がプリンターにない場合は、対象ページを示して印刷を止めます。両面印刷では、用紙・向きが変わる箇所に必要な空白の裏面を追加し、異なる用紙を同じ紙の表裏へ割り当てません。用紙トレイには必要な紙を用意してください。実機の給紙・両面処理はプリンタードライバーにも依存します。

PDF内の目次などの内部リンクはクリックすると該当ページへ移動します。文字をドラッグした場合は従来どおり選択でき、リンク移動は行いません。現在は同じPDF内のページ移動に対応しています。
