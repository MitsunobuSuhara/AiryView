# 画像編集・PDF書き込みの開発記録

2026-09-28。2.1.0のビルド・自動テスト完了。インストール結果はHANDOVER.md冒頭を参照。

## 実装

- `VisualEditorWindow` はツールバーのクリック時だけ生成。通常の起動・閲覧から編集画面、履歴、PDF補助プロセスを起動しない。
- 画像：左右90度回転、ドラッグ切り抜き、幅・高さ変更（縦横比維持）、文字・矢印・線。PNG/JPEGへ別名保存。JPEGは白背景、PNGは透明維持。合計3200万画素まで。
- PDF：ページを切り替えながら文字・矢印・線。現在のページだけプレビュー画像を保持。原本のCropBoxとRotateに逆変換してベクトルを重ねる設計。既存テキストやフォームを画像に置き換えない。
- Undo/Redo、原本と開いているファイルへの上書き拒否、作業中の終了確認。一時ファイルへ書いた後に保存先へ移動する。
- 画像は回転・切り抜き・サイズ変更で書き込みを一体化。Undoで直前の状態へ戻せる。保存後は書き込みオブジェクトの再選択はできない。画像のメタデータは引き継がない。GIF/TIFFは表示フレーム、SVGは表示用画像を使う。
