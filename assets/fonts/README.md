# 編集用の同梱フォント

MeCapitoのassets/fontsから変更せず複製した日本語フォント。各フォルダのOFL.txtに著作権表示とSIL Open Font License 1.1を同梱する。MeCapito側のファイルは変更していない。

- Noto Sans JP / notosansjp
- M PLUS 2 / mplus2
- Shippori Mincho（しっぽり明朝） / shipporimincho
- LINE Seed JP / lineseedjp
- IBM Plex Sans JP / ibmplexsansjp
- Zen Kaku Gothic New / zenkakugothicnew
- Zen Kaku Gothic Antique / zenkakugothicantique

アプリのFontsフォルダへ配布する。OSへフォントをインストールせず、編集画面で選択・描画するときだけ読み込む。7ファミリー（Regular/Boldまたは可変フォント）の元ファイルとライセンスは合計約50.2MiB。保存済みPDFの追加文字は輪郭図形なので閲覧先に同じフォントを要求しない。
